Cari Prakiraan Cuaca Kota (Open-Meteo API)

Data cuaca real-time global tanpa API key memanfaatkan standard modern Fetch API.

📋 Pemenuhan Syarat Tugas Praktikum Pertemuan 06

  • HTML, CSS, & JavaScript Murni (Vanilla JS): Tidak menggunakan framework/library eksternal (React/Vue/Axios), murni native fetch() dan DOM API.
  • Integrasi REST API Publik: Memanggil Open-Meteo API (Geocoding & Open-Source Forecast) serta GitHub Users API (https://api.github.com/users/{username}).
  • Kelengkapan Informasi: Menampilkan nama lokasi/avatar, koordinat/bio, suhu & kelembapan / repositori publik, serta tautan profil/data resmi.
  • Penanganan 3 Kondisi Wajib:
    1. Loading State: Menampilkan spinner animasi CSS dan indikator teks saat proses fetch() berlangsung.
    2. Success State: Menampilkan kartu informasi rapi saat response berstatus 200 OK.
    3. Not Found / 404 Error State: Menampilkan pesan ramah pengguna jika kota tidak ada atau status 404 (User tidak ditemukan).
